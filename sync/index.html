Backup & Restore

数据同步.

本站的数据只存在你这台浏览器里（localStorage），没有服务器、没有账号、没人能看见。代价是：换设备或清缓存，数据就没了。

会备份什么

账本全部流水记录（ledger-entries-v1）

备份文件为 JSON，文件名形如 homo-backup-2026-11-03.json。明文可读，别发给别人。

导出备份

把上面那些数据打包下载到本机。建议一个月导一次。

导入恢复

从备份文件恢复。替换会覆盖本机现有账本；合并会按 id 去重后相加。

危险区

只清本机数据，不可恢复。先导出备份再动手。

备份中不包含：网站源码（在 GitHub 仓库）、微博原文（在微博）。
